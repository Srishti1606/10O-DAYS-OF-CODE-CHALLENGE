# Day-68 (20 October 2026)

## Problem Statement
Write a program to take an input array of size n. The array should contain all the integers between 0 to n except for one. Print that missing number

### Sample Test Cases
```text
Input:  nums1 = [0,3,2,4]
Output: 1
```
```text
Input:  nums1 = [1,2,3]
Output: 0
```
```text
Input:  nums1 = [0,4,3,1,5]
Output: 2
```
