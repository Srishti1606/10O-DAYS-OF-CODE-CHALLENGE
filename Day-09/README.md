# Day-09 (18 August 2026)

## Question 1
Write a program to find the roots of a quadratic equation and categorize them.

### Sample Test Cases
```text
Input:  1 -3 2
Output: Roots are real and different: 2, 1
```
```text
Input:  1 -2 1
Output: Roots are real and same: 1
```
```text
Input:  1 2 5
Output: Roots are complex
```

## Question 2
Write a program that accepts a percentage (0-100) and assigns a grade based on the following criteria: 
90-100: Grade A 
80-89: Grade B 
70-79: Grade C 
60-69: Grade D 
below 60: Grade F.

### Sample Test Cases
```text
Input:  95
Output: Grade A
```
```text
Input:  82
Output: Grade B
```
```text
Input:  68
Output: Grade D
```
```text
Input:  50
Output: Grade F
```
